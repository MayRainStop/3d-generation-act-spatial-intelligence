# Task 1: 3DGS, AIGC 3D, and Object Fusion

This directory stores the local Task 1 supplement contributed after the main AutoDL result package: real object A reconstruction and Blender A/B/C scene fusion.

## Directory Layout

```text
object_a_reconstruction/
|-- notebooks/obj_a.ipynb
|-- data/object_a_data/          # local phone captures + COLMAP workspace
`-- outputs/object_a_3dgs/       # local 3DGS output for object A

blender_fusion/
|-- notebooks/newblender.ipynb
|-- scripts/
|   `-- render_colored_orbit_v5.py
|-- assets/input-assets/         # local meshes/textures
`-- outputs/                     # local rendered videos

aigc_pipeline_records/
|-- configs/task1_pipeline_example.json
|-- scripts/                     # helper scripts and command generators
|-- data/object_c_image3d/inputs/object_c_input.png
`-- outputs/                     # lightweight command summaries/templates
```

## Key Artifacts

- Object A input: 73 phone-captured images.
- Object A reconstruction: COLMAP sparse model plus 3DGS trained to iteration 7000.
- Object A export: `object_a_reconstruction/outputs/object_a_3dgs/point_cloud/iteration_7000/point_cloud.ply`.
- Fusion assets: reconstructed `counter` surface mesh, object A tissue mesh, object B pear-like textured mesh, and object C single-image textured mesh.
- Final video: `blender_fusion/outputs/object_fusion_orbit_v5.mp4`.
- AIGC pipeline records: `aigc_pipeline_records/` keeps Object B/C command provenance and a Zero123 input image, without vendoring full third-party source trees.
- Report figures: generated by `../../tools/plot_task1_object_fusion_figures.py`.

## Commands

Regenerate the object/fusion figures:

```bash
python tools/plot_task1_object_fusion_figures.py
```

Render the final 150-frame Blender orbit video:

```bash
blender -b -P tasks/task1_3dgs_aigc/blender_fusion/scripts/render_colored_orbit_v5.py
```

Large data, outputs, and rendered videos are intentionally local-only and ignored by Git.

Third-party frameworks are not vendored in the final folder. To rerun training, install or clone 3D Gaussian Splatting and threestudio outside Git-tracked files, then point the helper scripts to those local checkouts.
